
# Tablero de Prueba — GitHub Pages + SharePoint Embed

## Qué es esto

Repo de **prueba técnica**, sin datos reales, para validar si un tablero HTML autocontenido (JS vanilla + Chart.js) se puede:

1. Publicar como sitio estático en GitHub Pages.
2. Embeber dentro de una página de SharePoint usando el web part **Embed**.

Si esta prueba funciona, el mismo mecanismo se usa después para publicar el tablero real de Supervielle (Viva Engage + LinkedIn), pero en un hosting con control de acceso — **no en este repo público**.

## Contenido

- `index.html` — el tablero de prueba. Todos los nombres de comunidades, meses y métricas son ficticios (generados con una semilla fija, no aleatorios de verdad, para que los números sean siempre los mismos).

## Cómo verlo

Una vez activado GitHub Pages (ver pasos abajo), el sitio queda disponible en:

```
https://alemsotelo.github.io/tableroTest/
```
